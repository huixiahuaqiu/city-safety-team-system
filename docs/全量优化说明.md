# 全量优化说明

更新时间：2026-07-26

## 本轮已完成

- 安全：本地网关默认仅监听 `127.0.0.1`；跨域改为显式白名单；数据集、标注和共享文件读写均要求令牌；限制 JSON 请求体大小；补充 CSP、点击劫持、MIME 嗅探和隐私相关响应头。
- 账号：浏览器端密码由明文迁移为 PBKDF2-SHA256 校验记录；历史账号在登录或后台迁移时自动升级；云端同步前强制移除明文字段。
- 前端：任务、会议、日志链接等高风险展示点统一转义或校验 URL；共享文件和项目文档下载改为携带认证头的受控请求。
- 性能：模块 HTML 和大体积功能脚本按需加载，资源版本由构建脚本统一生成；首页云同步默认 15 秒、后台模块默认 60 秒，避免高频重复拉取。
- 体验：优化 1280、1024、768 和手机宽度下的导航、搜索框、内容区与浮动操作布局；生产环境可隐藏演示账号。
- 工程：修正项目脚本和依赖，补充 ESLint、单元测试、构建一致性检查与 CI。

## 部署前必须配置

从 `123123/.env.example` 创建部署环境变量，并至少设置：

- `DATASET_UPLOAD_TOKEN`
- `ANNOTATION_UPLOAD_TOKEN`
- `MLOPS_TOKEN`
- `CORS_ALLOW_ORIGINS`
- `AUTH_SIGNING_SECRET`
- `SUPABASE_SERVICE_ROLE_KEY`

生产环境还应在前端配置中设置：

```js
APP_ENV: 'production',
SHOW_DEMO_ACCOUNTS: false,
GATEWAY_AUTH_ENABLED: true
```

如使用 Supabase，请继续使用浏览器可公开的 publishable key，并确保数据库已启用正确的 RLS 策略；服务端高权限密钥只能放在环境变量中。

## 验证命令

在 `123123` 目录运行：

```powershell
npm run check
```

该命令会依次执行代码检查、回归测试和资源版本一致性检查。

## 兼容性说明

- 旧账号无需手工重置密码；首次成功登录后会自动迁移。
- 未配置上传令牌时，共享文件、数据集和标注接口会拒绝访问，这是预期的安全默认行为。
- 旧变量 `CORS_ALLOW_ORIGIN` 暂时兼容，建议迁移到支持逗号分隔白名单的 `CORS_ALLOW_ORIGINS`。
- 第二阶段已提供可选的网关会话认证：服务端校验 PBKDF2 验证器、签发短期 HMAC 会话，并对文件、标注、AI 与管理类接口执行角色校验。正式多租户场景仍建议迁移到 Supabase Auth 或独立身份服务，以获得 MFA、集中吊销和完整用户生命周期管理。
